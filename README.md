# Idealcare Website

A responsive single-page website for **Idealcare**, a medical equipment and home healthcare business.

## Included
- Responsive mobile/desktop design
- Idealcare branding
- Home wound-care services:
  - Chronic wound care
  - Bedsores / pressure sore care
  - Post-surgery wound care
- Medical equipment enquiry section
- Appointment booking form
- Appointment requests prepared automatically for WhatsApp
- Direct call and WhatsApp buttons
- Uses healthcare imagery instead of the supplied promotional poster

## GitHub Pages
Upload `index.html`, `styles.css`, `script.js`, `README.md`, and the `assets` folder to the repository root. The website will load from `index.html`.

## Important
The equipment categories are intentionally written as enquiry categories rather than claiming specific stock. Replace or expand them with the friend's actual products and prices once the inventory is confirmed.
